BroziRepo - Private APT Archive

This is a strictly authenticated Debian repository. Follow the steps below to onboard your system.

Step 1: Install prerequisites

sudo apt update && sudo apt install -y curl gnupg

Step 2: Import the cryptographic anchor

curl -fsSL http://<YOUR_SERVER_IP>:8888/repo-key.pub | sudo gpg --dearmor -o /etc/apt/keyrings/deb2repo.gpg

Step 3: Route the package manager

echo "deb [signed-by=/etc/apt/keyrings/deb2repo.gpg] http://<YOUR_SERVER_IP>:8888/ bookworm main" | sudo tee /etc/apt/sources.list.d/deb2repo.list

Step 4: Synchronize indexes

sudo apt update
